# RBAC Task Manager

## Overview
A web application that manages task access based on user roles. It implements JWT authentication and role-based authorization to protect routes and restrict unauthorized access.

## Tech Stack
- Node.js and Express.js
- JSON Web Tokens (JWT)
- Sequelize
- HTML, CSS, and JavaScript

## Features
- JWT-based user authentication
- Role-based access control
- Protected routes using middleware
- Task retrieval and database integration
